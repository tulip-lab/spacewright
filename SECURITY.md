# Security

SpaceWright controls macOS windows and Spaces through local tools. Treat config
changes as executable-environment changes even though the v1 data model does
not accept arbitrary shell commands.

Report vulnerabilities privately to the repository owners through GitHub's
private vulnerability reporting or another agreed private channel. Do not open
a public issue containing credentials, machine identifiers, or exploit details.

Before a public release, rerun the current-tree and full-history privacy audit
described in `docs/security-and-publication.md`.
